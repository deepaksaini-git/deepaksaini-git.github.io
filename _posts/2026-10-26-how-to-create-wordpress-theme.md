Aaj hum seekhenge ki WordPress theme bilkul zero se kaise banate hain bina kisi page builder ke.

## Pehla Step
Sabse pehle apne wp-content/themes folder mein ek naya folder banayein aur usme `style.css` aur `index.php` create karein.

## Dusra Step
Functions setup karne ke liye `functions.php` ka use karein.
